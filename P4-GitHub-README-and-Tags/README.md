# P4 - GitHub README and version tags

## Aim
To write a useful README file and practise adding a version tag.

## README details
A project README should tell someone what the project does, which files are included and how to open it.

## Git commands
```bash
git add README.md
git commit -m "Write project README"
git tag v1.0
git tag
git push origin main
git push origin v1.0
```
